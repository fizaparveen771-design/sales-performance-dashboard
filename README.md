Sales Performance Dashboard | Power BI

Project Overview

This project focuses on analyzing sales data to understand business performance across different product categories and time periods.

I developed an interactive dashboard using Microsoft Power BI to track key business metrics, identify sales trends, and present insights in a clear and structured format.

Business Objectives

- Analyze overall sales and profit performance.
- Compare sales across different product categories.
- Understand year-wise sales trends.
- Evaluate discount patterns and profit margins.
- Provide an interactive view of business performance.

Key Metrics

- Total Sales
- Total Profit
- Average Discount
- Average Profit Margin

Dashboard Highlights

- Category-wise sales analysis
- Year-over-year sales comparison
- Sales distribution across product categories
- Average discount visualization
- Interactive year and quantity filters

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

Key Learnings

Through this project, I gained practical experience in data cleaning, data modeling, creating DAX measures, designing interactive visualizations, and presenting business insights through dashboards.
